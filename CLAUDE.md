# recipi

Open-source SwiftUI recipe app for iOS (a free Mela alternative). See
README.md for the feature scope; v2 items are out of scope until v1 ships.

## Stack and conventions

- Swift 6 language mode with strict concurrency, SwiftUI, iOS 18 minimum (raise it
  only when a feature needs a newer iOS).
- MVVM with `@Observable` when a screen needs state beyond simple `@State`
  and `@Query`; plain views otherwise.
- SwiftData for storage, synced with CloudKit (private database). No backend.
- The Xcode project is generated by XcodeGen from `project.yml`. Edit
  `project.yml`, never the generated `.xcodeproj`, then run `xcodegen`.
- Code shared by the app and the share extension goes in
  `Packages/RecipiKit`. The `RecipiKit` target has no UI; screens go in the
  app or extension target.

## Look and feel

The `RecipiDesign` target (same package) is the design system: Notion-like
warm neutrals, system type, generous spacing, and color only where it means
something (tag colors, the paprika accent on actions, callouts).

- Use `Theme.Colors`, `Theme.Spacing`, `Theme.Radius` and `Theme.Fonts`, not
  raw colors or numbers. Every color has a light and a dark value.
- Tags get their color from `TagColor.forName(_:)`, which is stable across
  launches. Don't change its hash or palette order; that recolors tags.
- Animate with `Motion` and the helpers `withMotion(_:reduceMotion:)`,
  `.motion(_:value:)` and `.bounceEffect(value:)`, which turn movement off
  under Reduce Motion. Don't call `withAnimation` directly in screens.
- The minimum is iOS 18, so iOS 18 APIs (like the library-to-recipe zoom in
  `Recipi/Shared/ZoomTransition.swift`) need no `#available` check. Anything
  newer goes behind `#available`.

## SwiftData + CloudKit rules

These fail at runtime, not compile time:

- Every stored property needs a default value or must be optional.
- Every relationship must be optional and should declare an inverse.
- No `@Attribute(.unique)`. Dedupe by hand (see `Tag.findOrCreate`).
- Schema changes after release must be additive (new optional properties or
  new models only).

## Importing

`RecipeImporter` tries `SchemaRecipeParser` (JSON-LD) first, then
`FallbackRecipeParser`. When a real site fails, add its trimmed markup as a
test in `RecipeParserTests.swift` before changing the parser.

## Build and test

```sh
xcodegen
swift test --package-path Packages/RecipiKit
xcodebuild build -project Recipi.xcodeproj -scheme Recipi \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
```

Signing is per developer in `Config/Local.xcconfig` (gitignored). Releases are
signed with Justin's personal Apple Developer account, never a work account.
