# Security policy

recipi keeps your recipes on your device and in your own iCloud. There is no
recipi server and no account, so most security issues will be in how the app
reads web pages, stores data or talks to iCloud.

## Reporting a vulnerability

Please report it privately through GitHub: open the repository's **Security**
tab and choose **Report a vulnerability**. Don't open a public issue for it.

Include what you found, how to reproduce it (a recipe link or a trimmed page
is ideal), and which version of recipi and iOS you saw it on. recipi is
maintained by one person in their spare time, so replies may take a few days.
Once a fix ships, you can be credited in the release notes if you'd like.

## Supported versions

Only the latest release on the App Store and the `main` branch get fixes.
